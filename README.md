# Matchmaking

An application that lets people connect to potential matches based on assortative mating.

## Product vision

See the v1 product vision spec: [`docs/product-vision-v1.md`](docs/product-vision-v1.md).

### v1 north star (summary)

- Help users start more **safe, meaningful conversations** each week.
- Increase profile quality so matching has better signal from the start.
- Make discovery and Like/Pass decisions fast and low-friction.
- Convert mutual matches into first messages quickly.
- Maintain trust with baseline reporting, blocking, and anti-abuse protections.
